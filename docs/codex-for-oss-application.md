## Why this project qualifies

Qianchuan Automation Control is a newly public, production-tested OSS stack for safer OceanEngine Qianchuan ad operations. It combines OAuth, local audit storage, rule-based campaign actions, role-scoped UI, and a read-only MCP report interface. It targets a real automation gap for merchants managing many paid-promotion plans and gives operators a safer alternative to manual console work.

## Intended API-credit use

API credits would support automated security review, regression-test generation, refactoring of the local control proxy and OAuth broker, documentation upkeep, and agent-assisted analysis over sanitized Qianchuan report fixtures. The goal is to make campaign automation safer for maintainers while preserving strict boundaries between read-only analysis and live ad actions.

## Additional context

The public repository has been sanitized before release. It excludes production databases, report payloads, credentials, webhooks, internal hosts, shop identifiers, advertiser identifiers, and employee names. The project includes a safety scanner and documents the read-only agent boundary.
